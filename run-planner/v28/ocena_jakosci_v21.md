# Ocena jakości V21

Ocena wielokategorialna (`scoreV21` w `testy/lib.mjs`): bezpieczeństwo, poprawność harmonogramu, dopasowanie do biegacza, progresja, jakość treningów, specyfika dystansu, regeneracja. Kara zależy od gęstości problemów (bez sufitu), a wynik ogólny nie przekracza bezpieczeństwa+2 ani najsłabszej kategorii+2. To miernik heurystyczny, a nie dowód jakości.
