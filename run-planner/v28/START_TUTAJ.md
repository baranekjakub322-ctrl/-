# Run Planner V23

Bieżący generator: `planGenerator_v23.js`; model: `model/*v23.mjs`, zachowane wspólne `model/training.mjs`; niezależna ocena: `scoring/v23.mjs`.

Czytaj `README.md`, `SYSTEM_OCENIANIA_V23.md`, `raport_testow_v23.md`, `analiza_10k_3dni_v23.md` i ograniczenia. Uruchom `npm test`, potem `npm run report`. Nie trzeba instalować pakietów.

`wyniki_v23` to aktualne uruchomienie; `wyniki_bazowe_v22` to ponowiona baza. Pozostałe starsze raporty nie są wynikami V23. Oryginalny pakiet V22 jest w `baseline/RunPlanner_V22.zip`. Wszystkie szczegółowe plany i dane wejściowe znajdują się w `przyklady_v23`.
