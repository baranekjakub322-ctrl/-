# Ocena jakości V22

Najważniejsze zmiany dotyczą bezpieczeństwa przy małej częstotliwości, oddzielenia obecnej formy od celu, maratońskiej specyfiki, rzeczywistej historii i narastania trudności. Wyniki porównania są w [porównaniu](porownanie_v21_v22.md); nie przypisujemy arbitralnej ogólnej oceny sportowej.

Dotychczasowe progi pozostają bez zmian; nowy miernik stosuje te same reguły do obu wersji. Kategorie: bezpieczeństwo, wykonalność, progresja, intensywność, kalendarz, specyfika dystansu, regeneracja, czytelność. Każde naruszenie jest zapisane; wynik kategorii maleje wykładniczo z liczbą problemów, bez sufitu liczby kar. Kod i dokładny wzór są opisane w changelogu.

Miernik ma ograniczoną rozdzielczość: wiele planów otrzymuje 10 mimo częściowej gotowości. Nie traktujemy tego jako ideału i nie zmieniamy metryki, aby wywołać większy wzrost. Progi 180/195 min, RPE i limity progresji to jawne heurystyki, nie empirycznie skalibrowane wartości dla każdego biegacza. Ich tolerancję trzeba weryfikować w realizacji planu.

Pozostałe ograniczenia: brak klinicznej kwalifikacji, indywidualnej historii tolerancji, warunków trasy i długoterminowych danych realizacji. Niezmieniona część starszego API analizy/przeplanowania nadal wymaga dalszych testów danych rzeczywistych. V23 powinna zacząć się od walidacji prospektywnej i analizy zgłaszanych obciążeń, nie od podwyższania punktacji.
